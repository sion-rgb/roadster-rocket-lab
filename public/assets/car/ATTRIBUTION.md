`roadster-mobile.glb` is a reduced-detail adaptation made for this simulator using glTF Transform 4.5.1 and meshoptimizer 1.3.0. It retains the same materials, UV coordinates, normals and wheel hierarchy, with topology-aware index simplification targeting a 0.30 ratio and maximum relative error 0.005. It contains 201,937 triangles compared with 608,769 in the original and uses Draco compression. Both model files retain this CC BY 4.0 attribution and license.

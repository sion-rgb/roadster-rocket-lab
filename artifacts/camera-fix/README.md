# v1.1.1 第一身鏡頭穩定修正

第一身原本與追蹤鏡頭共用 79 / 93 rad/s 的人工火箭震動，位置跟隨係數為 40、視線為 8，導致車廂與視線不同步；固定 60 Hz 物理也直接用於不同更新率的畫面。

修正後，座艙取消人工震動；車模、座位、視線與反射共用位置 / 四元數插值。GSAP 切鏡完成後，鏡頭固定於車內的駕駛位置；俯仰、翻滾及滑鼠環視仍然生效。追蹤視角保留原有火箭震動。暫停保持插值位置，重置直接同步，避免拖影或瞬移路徑。

## 量測與驗證

Windows Chrome，正式 build / preview，1280×800；另有 390×844 的觸控瀏覽器模擬。手機測試並非實體手機效能認證。

| 場景 | 結果 |
| --- | --- |
| 舊版懸停 150 幀基線 | 座位相對左右擺幅 13.65 mm、上下擺幅 12.56 mm |
| 舊版前進 150 幀基線 | 最大座位偏離約 223 mm |
| 修正版 120 幀懸停 / 前進飛行 | 相對座位偏移 <0.001 mm，非操作造成的方向誤差 <0.00001° |
| 道路加速 / 轉向、俯仰 / 翻滾 | 座位與鏡頭同步，保留車身姿態 |
| 滑鼠環視 | 轉頭約 20°，之後保持穩定的車廂相對視線 |
| 暫停 / 重置 | 不累積震動；車模與鏡頭一同重置 |
| 三種視角 / 第一身降落 | 動畫完成，正常著地，無 crash |
| 390px 觸控瀏覽器 | 第一身按鈕、起飛及懸停通過 |

數值量測的是鏡頭相對車廂的額外位移；車輛真正的碰撞、懸掛、玩家俯仰及翻滾仍會改變畫面。舊版基線與修正版為分開的操作錄取，並非相同輸入的固定軌跡重播。
